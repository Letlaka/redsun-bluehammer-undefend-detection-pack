# Code of Conduct

## Purpose

This repository is intended for collaborative detection engineering, defensive security research, and Microsoft Defender XDR hunting content. Participation should remain professional, evidence-based, and focused on improving defensive outcomes.

## Expected Behavior

Contributors and participants are expected to:

- Communicate respectfully.
- Discuss technical disagreements with evidence.
- Keep feedback specific and actionable.
- Protect sensitive information.
- Avoid sharing unredacted production incident data.
- Respect legal, ethical, and organizational boundaries.
- Use this repository for defensive and educational purposes.

## Unacceptable Behavior

Unacceptable behavior includes:

- Harassment, threats, or discriminatory comments.
- Personal attacks.
- Publishing private information without permission.
- Sharing secrets, credentials, customer data, or unredacted incident data.
- Encouraging unauthorized access, abuse, or operational harm.
- Submitting weaponized payloads or exploit code.
- Misrepresenting unvalidated content as production-approved.

## Security Research Boundaries

This repository may discuss attacker techniques and detection logic. Contributions must stay on the defensive side of that boundary.

Do not add:

- Working exploit payloads.
- Instructions for unauthorized compromise.
- Bypass procedures intended to evade detection.
- Sensitive details from real incidents without authorization and sanitization.

## Enforcement

Repository maintainers may remove content, close issues, block participants, or reject contributions that violate this code of conduct.

If you see behavior that violates this document, report it through the support or security process described in `SUPPORT.md` and `SECURITY.md`.
